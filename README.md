# XO Arena 🎮

A multiplayer Tic-Tac-Toe game developed using C programming language.

## Features
- Two-player gameplay
- 3x3 game board using 2D arrays
- Win detection
- Draw detection

## Technologies Used
- C Programming Language
- 2D Arrays
- Conditional Statements
- Loops

## How to Run
Compile using GCC:

```bash
gcc tictactoe.c -o xo-arena
```

Run on Windows:

```bash
xo-arena.exe
```

Run on Linux/macOS:

```bash
./xo-arena
```
